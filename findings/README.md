# Findings

What the analyses have found, one small file per finding, in a folder per decision of the
[decision register](../registers/decisions/README.md) it serves: `findings/<DEC-nnnn>/<date>_<slug>.md`. Proposed in
[141](../docs/10_architecture/141_the-first-slice-business-vault-and-mart.md) §6.

A findings note states the knowledge date its figures are as known on, the decision it serves, the analysis it reads,
who wrote it and what it does not show. It is written by the agent layer from the analysis's result and is a proposal
to the person who owns the decision: it is unreviewed and not adjudicated until someone says otherwise in it.
