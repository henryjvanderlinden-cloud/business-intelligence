# ADR-0034 — The model is declared in small text files under `model/`, and viewed in a static page with no library

## Options considered

*The declaration language.* YAML or LinkML ([142](../10_architecture/142_the-data-model.md) §8): widely known, with
tooling that generates schemas and documents. Against them for now: `ARC-OP-20` puts languages after principles, and
the checker would need a dependency. The analysis record's flat grammar (front matter of `key: value`, entries
`- subject | key=value`) is read by the standard library and already read by agents here. Adopted: the flat grammar.

*The viewer's layout.* A vendored library such as d3-force: robust and well known. Against it: a dependency to vendor
or fetch from a CDN for a graph of a few hundred nodes. Adopted: a small force layout written into the page.

## Decision

1. **The model lives in a top-level folder `model/`**, beside `analysis/`, laid out as in `model/README.md` §1.
2. **The declarations use the grammar of `model/README.md`** §2 to §5, as revised after sol's review: one file per
   hub, link, satellite and reference table, plus one per source; only decisions declared; types, hash keys, clocks and
   the audit, status-tracking and effectivity satellites generated by rule; permanent ids; names and aliases never
   reused; one mapping per line or pair of lines.
3. **The viewer uses no library**: one static page generated from `model/` and the analysis record's catalogue, with
   its own force layout. It reads and never holds a copy of the model (142 §3).
4. **The six links from a line take an unknown business start of effectivity**: links 26, 27, 35, 36, 39 and 40 of
   [148](../10_architecture/148_wwi-relationships.md), whose driving hub is a line with no date of its own (147 §5).
   Their effectivity starts at load, with valid time explicitly unknown, as the lines' own satellites have
   (149 §3.4, §3.5).
5. **Link 28, invoice of order, is optional**, because its column is nullable although never empty in the data; its
   column is kept as delivered in `sat_invoice__wwi` (149 Rule 5).

## Consequences

The Wide World Importers raw vault exists as declarations and is checked on every run: every one of the 368 source
columns has exactly one disposition. The generator of ADR-0032 can now be designed against files; the ordering and
tie-breaking of versions with equal source system time, and late arrivals, are owed by that design (`ARC-OP-29`).

The format is ruled; its revision after review is unreviewed on another model. The viewer is a prototype under
`prototypes/` and its look is the author's to direct.

**Revisit** if a second source needs mappings with joins or filters, which the format does not yet hold; if the
viewer's layout fails on a model several times larger; or when `ARC-OP-20` ratifies principles that point to another
declaration language.
