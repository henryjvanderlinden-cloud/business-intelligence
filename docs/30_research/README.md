# Research notes

Working notes, tool evaluations and reading. Distinct from
[`../00_concept/050_prior-art.md`](../00_concept/050_prior-art.md), which is a register
of leads with one-line verdicts; this directory holds the work behind those verdicts.

Conventions: one file per subject in `notes/`, named `YYYY-MM-DD-subject.md`, opening
with what question the note was trying to answer. Sources cited inline. A note that
changes the design ends with a link to the ADR it produced, or an entry added to
[`../00_concept/040_open-questions.md`](../00_concept/040_open-questions.md).

Notes are allowed to be wrong and are not revised in place; supersede them.
